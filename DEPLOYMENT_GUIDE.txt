================================================================
   DEPLOYMENT GUIDE — Render (Backend) + Vercel (Frontend)
================================================================

PREREQUISITES
--------------
- GitHub account
- Render account (render.com)
- Vercel account (vercel.com)
- MongoDB Atlas account (mongodb.com/atlas) — replaces local MongoDB
- Your project pushed to a GitHub repository

================================================================
STEP 1: SET UP MONGODB ATLAS (Cloud Database)
================================================================

1. Go to https://mongodb.com/atlas and sign in.

2. Create a new Project and click "Build a Database".

3. Select FREE tier (M0), choose a region, click "Create".

4. Under Security > Database Access:
   - Click "Add New Database User"
   - Set a username and password (save these!)
   - Set role to "Read and Write to Any Database"
   - Click "Add User"

5. Under Security > Network Access:
   - Click "Add IP Address"
   - Click "Allow Access from Anywhere" (0.0.0.0/0)
   - Click "Confirm"

6. Go to Databases > Connect > Drivers:
   - Select Node.js
   - Copy the connection string. It looks like:
     mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority

7. Replace <username> and <password> with your actual credentials.
   Also add your DB name before the "?":
   mongodb+srv://user:pass@cluster0.xxxxx.mongodb.net/e-commerce?retryWrites=true&w=majority

   Save this full string — you'll need it in Step 2.

================================================================
STEP 2: PREPARE BACKEND FOR DEPLOYMENT
================================================================

1. Open backend/db/config.js and update it to use an env variable:

   CHANGE THIS:
   mongoose.connect('mongodb://localhost:27017/e-commerce')

   TO THIS:
   mongoose.connect(process.env.MONGO_URI)

2. Open backend/index.js and make sure the port uses env variable:

   CHANGE THIS:
   app.listen(5000);

   TO THIS:
   app.listen(process.env.PORT || 5000);

3. Also update the CORS config in backend/index.js to allow
   your future Vercel frontend URL:

   CHANGE THIS:
   app.use(cors());

   TO THIS:
   app.use(cors({
     origin: process.env.FRONTEND_URL || '*'
   }));

4. Open backend/package.json and confirm "main" is "index.js".
   Add a start script if missing:

   "scripts": {
     "start": "node index.js"
   }

5. Make sure backend/node_modules is in your .gitignore (it is).

6. Commit and push all changes to GitHub:
   git add .
   git commit -m "prepare backend for deployment"
   git push

================================================================
STEP 3: DEPLOY BACKEND ON RENDER
================================================================

1. Go to https://render.com and sign in.

2. Click "New +" → "Web Service".

3. Connect your GitHub account and select your repository.

4. Configure the service:
   - Name:        your-app-backend (any name)
   - Region:      Choose closest to you
   - Branch:      main (or master)
   - Root Directory: backend
   - Runtime:     Node
   - Build Command:  npm install
   - Start Command:  node index.js

5. Scroll down to "Environment Variables" and add:

   Key             Value
   -------         -------
   MONGO_URI       (paste your MongoDB Atlas connection string)
   jwtKey          your-secret-key-here   ← match what's in index.js
   FRONTEND_URL    (leave blank for now; add after Step 4)
   PORT            5000

   NOTE: In index.js the jwtKey is hardcoded as 'secret'.
   For production, change that line to:
   const jwtKey = process.env.JWT_SECRET || 'secret';
   Then set JWT_SECRET env var on Render.

6. Click "Create Web Service".

7. Render will build and deploy. Wait for status to show "Live".

8. Copy your backend URL — it looks like:
   https://your-app-backend.onrender.com

   Test it by visiting: https://your-app-backend.onrender.com/products
   (You'll get a token error — that's fine, it means it's running!)

================================================================
STEP 4: PREPARE FRONTEND FOR DEPLOYMENT
================================================================

1. You currently have hardcoded URLs like:
   http://localhost:5000/register
   in every component (SignUp, Login, AddProduct, etc.)

   Create a file: frontend/src/config.js
   with this content:

   const API_BASE = import.meta.env.VITE_API_URL || 'http://localhost:5000';
   export default API_BASE;

2. In every component that calls fetch(), replace the base URL:

   EXAMPLE in SignUp.jsx:
   CHANGE:  fetch('http://localhost:5000/register', ...)
   TO:      import API_BASE from '../config';
            fetch(`${API_BASE}/register`, ...)

   Do this for ALL components:
   - SignUp.jsx       → /register
   - Login.jsx        → /login
   - AddProduct.jsx   → /add-product
   - ProductList.jsx  → /products
   - UpdateProduct.jsx→ /products/:id

3. Create frontend/.env.local (for local dev, already gitignored):
   VITE_API_URL=http://localhost:5000

4. Commit and push all changes to GitHub:
   git add .
   git commit -m "prepare frontend for deployment"
   git push

================================================================
STEP 5: DEPLOY FRONTEND ON VERCEL
================================================================

1. Go to https://vercel.com and sign in.

2. Click "Add New..." → "Project".

3. Import your GitHub repository.

4. Configure the project:
   - Framework Preset:  Vite
   - Root Directory:    frontend
   - Build Command:     npm run build  (auto-detected)
   - Output Directory:  dist           (auto-detected)

5. Expand "Environment Variables" and add:

   Key              Value
   --------         -------
   VITE_API_URL     https://your-app-backend.onrender.com
                    (the Render URL from Step 3, Step 8)

6. Click "Deploy".

7. Vercel builds and deploys. When done, you get a URL like:
   https://your-app-frontend.vercel.app

8. Test your app by visiting that URL.

================================================================
STEP 6: CONNECT FRONTEND URL BACK TO RENDER (CORS FIX)
================================================================

1. Go to Render → your web service → Environment.

2. Add or update the variable:
   FRONTEND_URL    https://your-app-frontend.vercel.app

3. Click "Save Changes". Render will auto-redeploy.

4. Your app should now be fully working end-to-end.

  PORT            5000

VERCEL (Frontend):
  VITE_API_URL    https://your-backend.onrender.com
