================================================================
   DEPLOYMENT GUIDE — Render (Backend) + Vercel (Frontend)
================================================================

PREREQUISITES
--------------
- GitHub account
- Render account (render.com)
- Vercel account (vercel.com)
- MongoDB Atlas account (mongodb.com/atlas) — replaces local MongoDB
- Your project pushed to a GitHub repository

================================================================
STEP 1: SET UP MONGODB ATLAS (Cloud Database)
================================================================

1. Go to https://mongodb.com/atlas and sign in.

2. Create a new Project and click "Build a Database".

3. Select FREE tier (M0), choose a region, click "Create".

4. Under Security > Database Access:
   - Click "Add New Database User"
   - Set a username and password (save these!)
   - Set role to "Read and Write to Any Database"
   - Click "Add User"

5. Under Security > Network Access:
   - Click "Add IP Address"
   - Click "Allow Access from Anywhere" (0.0.0.0/0)
   - Click "Confirm"

6. Go to Databases > Connect > Drivers:
   - Select Node.js
   - Copy the connection string. It looks like:
     mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority

7. Replace <username> and <password> with your actual credentials.
   Also add your DB name before the "?":
   mongodb+srv://user:pass@cluster0.xxxxx.mongodb.net/e-commerce?retryWrites=true&w=majority

   Save this full string — you'll need it in Step 2.

================================================================
STEP 2: DEPLOY BACKEND ON RENDER
================================================================

1. Go to https://render.com and sign in.

2. Click "New +" → "Web Service".

3. Connect your GitHub account and select your repository.

4. Configure the service:
   - Name:            your-app-backend (any name)
   - Region:          Choose closest to you
   - Branch:          main (or master)
   - Root Directory:  backend
   - Runtime:         Node
   - Build Command:   npm install
   - Start Command:   npm start

5. Scroll down to "Environment Variables" and add:

   Key             Value
   -------         -------
   MONGO_URI       (paste your MongoDB Atlas connection string from Step 1)
   JWT_SECRET      your-secret-key-here   ← used for token signature/verification
   FRONTEND_URL    (leave blank for now; add after Step 3)
   PORT            5000

6. Click "Create Web Service".

7. Render will build and deploy. Wait for status to show "Live".

8. Copy your backend URL — it looks like:
   https://your-app-backend.onrender.com

   Test it by visiting: https://your-app-backend.onrender.com/products
   (You'll get a token error — that's fine, it means it's running!)

================================================================
STEP 3: DEPLOY FRONTEND ON VERCEL
================================================================

1. Go to https://vercel.com and sign in.

2. Click "Add New..." → "Project".

3. Import your GitHub repository.

4. Configure the project:
   - Framework Preset:  Vite
   - Root Directory:    frontend
   - Build Command:     npm run build  (auto-detected)
   - Output Directory:  dist           (auto-detected)

5. Expand "Environment Variables" and add:

   Key              Value
   --------         -------
   VITE_API_URL     https://your-app-backend.onrender.com
                    (the Render URL from Step 2, Step 8)

6. Click "Deploy".

7. Vercel builds and deploys. When done, you get a URL like:
   https://your-app-frontend.vercel.app

8. Test your app by visiting that URL.

================================================================
STEP 4: CONNECT FRONTEND URL BACK TO RENDER (CORS FIX)
================================================================

1. Go to Render → your web service → Environment.

2. Add or update the variable:
   FRONTEND_URL    https://your-app-frontend.vercel.app
   
   (Note: If you want to allow multiple origins like local dev or staging URLs,
   you can separate them with commas, e.g., https://your-app.vercel.app,http://localhost:5173)

3. Click "Save Changes". Render will auto-redeploy.

4. Your app should now be fully working end-to-end.

================================================================
ENVIRONMENT VARIABLES SUMMARY
================================================================

RENDER (Backend):
  MONGO_URI       mongodb+srv://user:pass@cluster.mongodb.net/e-commerce?...
  JWT_SECRET      some-long-random-secret-string
  FRONTEND_URL    https://your-app.vercel.app (or multiple comma-separated URLs)
  PORT            5000

VERCEL (Frontend):
  VITE_API_URL    https://your-backend.onrender.com
